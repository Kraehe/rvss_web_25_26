# Portfolio Starter

Welcome to your portfolio starter! Here's what's inside and how to use it.

## File Structure

```
portfolio-starter/
├── index.html         ← homepage
├── about.html         ← about me page
├── projects.html      ← projects showcase page
├── css/
│   └── style.css      ← all the styling (shared across all pages)
├── js/
│   └── script.js      ← optional JavaScript
└── images/
    └── (put your images here)
```

## How to Use This

1. **Open the folder in VS Code** (File → Open Folder).
2. **Open `index.html` in your browser** to see the starter site.
3. **Replace `[Your Name]`** everywhere you see it (in all 3 HTML files).
4. **Add your images** to the `images/` folder. The starter expects:
   - `profile.png` — your profile picture for the About page
   - `cookie-clicker.png`, `poem.png`, `flag.png`, `form.png` — screenshots of your projects
   - You can use ANY image filenames, just update the `<img src="...">` to match.
5. **Customize the colors and fonts** in `css/style.css` — look for the `:root` section at the top!

## Things to Try

- Change `--main-color` in `style.css` to your favorite color
- Add a new project card in `projects.html` (copy one of the existing `.project-card` divs)
- Link your old projects (cookie clicker, poem, etc.) by changing `href="#"` to the path of your project
- Add fun facts, more interests, or new sections to the About page
- Uncomment the `alert()` in `js/script.js` to greet visitors

## Tips

- **Keep the navbar the same** on every page so visitors can navigate easily.
- **Use the same stylesheet** (`css/style.css`) on every page so your site looks consistent.
- **Check your image paths** — if an image doesn't show up, the filename or folder is probably wrong.

Have fun! 🎨
